# @flatscout/browser-bridge

## 1.0.0

### Major Changes

- Initial v1.0.0 release.

  Self-hosted, MIT-licensed apartment-hunting agent for the Swiss market. Five source plugins (Flatfox, Homegate, ImmoScout24, RealAdvisor, Immobilier.ch + generic schema.org adapter), Telegram notifier, commute enricher, persistence layer, CLI, and the browser-bridge subsystem used to bypass anti-bot stacks on DataDome/Cloudflare-protected portals.
